01 // TENTANG SAYA

Tentang Saya

Perpaduan ketelitian teknologi jaringan & database dengan disiplin, ketangguhan mental, dan sportivitas tinggi.

Aurel Ayu Puspitasari

Siswi TJKT SMKN 1 Blitar & Atlet Pencak Silat Berprestasi

Halo! Saya Aurel Ayu Puspitasari, siswi aktif jurusan Teknik Jaringan Komputer dan Telekomunikasi (TJKT) di SMKN 1 Blitar. Di bidang teknologi, saya mendalami administrasi jaringan komputer, konfigurasi perangkat jaringan, perancangan struktur basis data (database), serta pengembangan aplikasi kasir untuk mendukung pencatatan transaksi secara tertib dan akurat.

Selain menekuni dunia teknologi, saya aktif sebagai Atlet Pencak Silat berprestasi. Pengalaman bertanding di berbagai kejuaraan melatih saya untuk memadukan ketelitian analisis di depan layar komputer dengan disiplin tinggi, ketangguhan mental, fokus, dan sportivitas di arena pertandingan.

TJKT / Database SQL & Relasi Data

Sistem & Manajemen Database

Perancangan struktur tabel basis data relasional, pemodelan relasi antar data, serta pengelolaan query SQL untuk memastikan penyimpanan, pencarian, dan pembaruan informasi berjalan terstruktur dan akurat.
